# Welcome to efemde

This is a sample markdown file to test the editor.

## Features

efemde is a fast markdown editor for macOS with several key features:

- **Split View**: Edit and preview side-by-side
- **Syntax Highlighting**: Color-coded markdown elements
- **Live Preview**: Real-time HTML rendering
- **QuickLook Support**: Press Space in Finder to preview

## Markdown Examples

### Text Formatting

You can make text **bold** or *italic*. You can also combine them: ***bold and italic***.

### Code

Inline code looks like this: `const greeting = "Hello, World!";`

Code blocks look like this:

```javascript
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet("efemde"));
```

## Quick Start

1. Open a `.md` file or create a new one
2. Start typing in the left editor pane
3. See the rendered preview on the right
4. Save your work with `⌘S`

## Tips

- Use `⌘N` to create a new document
- Use `⌘O` to open an existing document
- The editor auto-saves your changes
- Dark mode is automatically supported
